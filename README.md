# NowRSS
NowRSS is an RSS/Atom reader, using Now Cards (v2.7.3) background.
For Android 4.0+, it supports TLS 1.2

# Requirememts
The `minSdkVersion` is 14, compatible with Android 4.0 "Ice Cream Sandwich"
The "targetSdkVersion" is 23 (Android 6.0 "Marshmallow")

# Building
To build, open in Android Studio (or `gradle assembleDebug`).
